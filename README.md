# SWYNEX Dataset Exploration & Preprocessing

## Project Overview
This project focuses on exploring and preprocessing the Titanic dataset for machine learning.

## Tasks Performed
- Explored the dataset using Pandas
- Checked dataset shape and information
- Identified missing values
- Filled missing Age values using the median
- Filled missing Embarked values using the mode
- Removed unnecessary columns
- Encoded categorical variables
- Separated features and target variable
- Split the data into training and testing sets
- Created a survival distribution visualization

## Dataset
The Titanic dataset contains passenger information and the target variable `Survived`.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Conclusion
The Titanic dataset was successfully explored and preprocessed, and the resulting data was prepared for machine learning model training.
